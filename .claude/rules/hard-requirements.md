# 硬要求

- 回复用中文。
- 不用 memory 功能，不写 memory 文件。不自己建 `AGENTS.md`、`CLAUDE.md`；仓库根目录的 `CLAUDE.md` 是用户自己的，照它做，不提交、不修改。
- 只在用户说发布时发布，不提议发布；用户说了以后按 `docs/development.md` 的发布流程一路做完，检查不过才停。
- 不改用户的 Clash 代理规则。
- 测试不读、不改用户真实的设置和数据；窗口放在屏幕外（`VA_E2E_BACKGROUND=1`）；会安装程序、改真实 PATH 或已安装程序的测试只在 GitHub 上跑，用临时目录、临时注册表项隔离的可以在本机跑。
- 脚本输出凡涉及 DeepSeek 的请求和响应都要过滤：里面带登录令牌。
- 结束进程按 PID，不按映像名。
- 明显的错直接改，改完说明；产品决定、对外的或不可撤销的步骤先问。不加没人要求的白名单、限制和防御性上限。
- 文档、代码注释、提交信息、规则文件写规整后的说法，不抄用户原话、不记讨论经过。用户的决定在文档里那句话后面标「（用户定）」，日期写在提交信息里，写成「（用户 YYYY-MM-DD 定）」；代码注释不标。文档怎么分见 `docs/doc-rules.md`，写法见 `docs/writing.md`。
- 提交信息不带 AI 署名。
