# Summary depth — user decision (2026-10-27)

The user found summaries shallow. Besides the missing screen pages, the rules asked for it: the first rule, "Map, don't retell", gave only an overview, main points and a timeline unless the user asked for more (a default taken over from upstream in 0.1.0, not a user decision), `summary-context.md` asked for a "concise" summary, and 详细内容 had one line of guidance. Now 详细内容 is the body: part by part, what a viewer would note down, with a length that follows how much the video says, shortened only on request; pictures are worked in where they add something, without a duty to mention each one. The user asked that the rules name no subject or kind of video (they apply to every video) and not require every screen page.

Revised 2026-10-28 (user decision, wording Claude judgment) after DeepSeek's and Gemini's web chats summarized the third NJU lecture from the same material and came out unlike each other: DeepSeek retold the talk in order in paragraphs of over a thousand characters, Gemini wrote scannable notes but put history the video does not give (Git written in two weeks, BitKeeper's licence withdrawn over reverse engineering) among the speaker's points, wrote advice as "严禁" and linked a slide from twenty minutes later. The rules now ask for notes a reader can scan rather than the talk retold sentence by sentence, the form of each part left to its content (a fixed shape per part was proposed and rejected as too rigid); allow additions beyond the video, which the user wanted, each starting with `补充：` so it is never taken for the speaker's; keep the speaker's strength as well as hedges; and link the picture shown at the point described.
