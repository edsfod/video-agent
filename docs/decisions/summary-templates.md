# Summary templates — user decisions (2026-10-27, several 2026-10-29)

The rules and template a summary follows are a summary template. Several exist side by side (user request, 2026-10-29) and one is chosen: the built-in `标准` (`prompts/summary.md`) and `命题分析` (`prompts/propositions.md`), and the user's own, Markdown files in `%APPDATA%\video-agent\templates`. A user file with a built-in's name is the user's edited copy of it, which replaces it everywhere; its first line records a fingerprint of the built-in it came from, so when an update changes the built-in, `template` warns on stderr, `--info` reports `outdated` and writes the new built-in to `templates\.defaults\` for comparing, and `--accept` records that the user merged it. Updates never change the user's files. `template --use NAME` chooses (setting `template`); `summarize` and `pack` take `--template NAME` for one summary; the GUI's tasks keep the template they were added with, pass it to the CLI, and tell an Agent to follow `video-agent template "NAME"`. Before 0.9.3 there was one copy, `%APPDATA%\video-agent\summary.md`: a copy that is a built-in word for word is removed and that template chosen, any other becomes the user's copy of `标准`.

`命题分析` follows the user's design (2026-10-29): first the 元信息 (type, speaker, scope, what is assumed known, and under 需留意 what is not true or false but is to be done or remembered: attendance, assignments, assessment and grading, course requirements, notices); then the video as a structure of propositions, each tagged 事实, 观点, 推断 or 引用, with the line of argument drawn out; within a proposition, the user's how-to-discuss method (regimentation, the reasonable and charitable reading, ambiguities listed as exclusive and exhaustive options, a formal version where words blur the structure). **Claude judgment:** the tags are asked in the order 引用, 观点, 推断, 事实 and the first that fits is taken, so each proposition has one; a tag records how the speaker presents a claim, not whether it is true; a premise the video needs but does not state is added as `补全`, the weakest that makes the step work; 论证结构 replaces 要点, and the lecture-only 要点速查 is folded into 需留意; 时间线 stays.

`SKILL.md` stays read-only (the GUI shows it in a dialog): every update replaces the plugin files, so edits would be lost. Personal preferences go into a template. In the GUI: the summary page's 模板 drop-down (the collection's overview and study guide use it too) and 设置 → 总结模板 (编辑, 打开新版对比, 已合并, 恢复自带的, 删除, 新建 from any template, 查看 skill).
