# Distribution — user decision (2026-10-27, 0.1.1)

The 0.1.0 install asked for uv, FFmpeg and, without saying so, git (`uv tool install git+https://…` fails without it). The user chose to remove these steps:

- **Dependencies.** FFmpeg comes from `imageio-ffmpeg` and yt-dlp from PyPI, both declared in `pyproject.toml`. Tools on `PATH` are preferred. `imageio-ffmpeg` has no ffprobe, so `media.probe` reads the needed facts (streams, codecs, languages, duration) from ffmpeg's banner when ffprobe is missing; a test checks both give the same answer. `download` passes `--ffmpeg-location` so yt-dlp merges streams with the same ffmpeg.
- **No git.** The README, the skill and the GUI's last-resort `uvx` use the wheel attached to the GitHub release instead of a `git+` URL. Installing the Agent plugin from GitHub with `claude`/`codex plugin marketplace add edsfod/video-agent` still needs git (both fail with git hidden from `PATH`, checked 2026-10-27), so the desktop app has buttons that install it from its local copy.
- **Desktop installer bundles everything.** `packaging/build_cli.py` freezes the CLI with PyInstaller (Python, yt-dlp and, since 2026-10-28, its own LGPL FFmpeg instead of imageio-ffmpeg's GPL build, see [Bundled FFmpeg](bundled-ffmpeg.md); about 118 MB) into `resources/cli`; the installer grew from 126 MB to 167 MB and needs no network. A frozen build has no `python -m`, so the bundled yt-dlp runs as `video-agent _yt-dlp`. The GUI uses a CLI set in its settings first, then the bundled one, then `video-agent` on `PATH`; its jobs and terminals see the bundled folder first on `PATH`.
- **PATH and shortcuts.** The installer appends `resources\cli` to the user's `PATH` and the uninstaller removes it (`gui/installer/`). Since 0.2.0 a page after the folder choice says so, with a checkbox that is on by default (SignPath's rule to announce system changes); the choice is kept in `HKCU\Software\Video Agent` for updates and silent installs, and CI checks both ways. Desktop and Start menu shortcuts are electron-builder's defaults. electron-builder also copies the installer (about 160 MB) to `%LOCALAPPDATA%\video-agent-gui-updater`; the updater uses it for differential downloads (see [Updates](updates.md)), and the uninstaller removes the folder, which electron-builder's own uninstaller leaves behind (0.1.1 left it). **Claude judgment:** appending, not prepending, keeps a CLI the user installed themselves first in terminals. The script edits `HKCU\Environment` through the registry API with `DoNotExpandEnvironmentNames` and keeps the value type, because `[Environment]::GetEnvironmentVariable` returns expanded text and writing it back would turn entries like `%USERPROFILE%\bin` into fixed paths. Checked on 2026-10-27 with silent install and uninstall: `PATH` came back byte-identical and both shortcuts were removed.

## Packaging

- Packaging: `npm run dist` freezes the CLI and builds an unsigned NSIS installer; node-pty's N-API prebuilds are used as is (`npmRebuild: false`); the plugin files go to `resources/plugin`.
