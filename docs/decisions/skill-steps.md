# Skill steps in code — user request (2026-10-29)

What the skill asked the Agent to remember or do by hand, and a program can do, is code. Then (user decision, same day: most of the rest was unneeded, consent included) `SKILL.md` was cut to a map of the commands, about a quarter of its size: what a command needs to say, it says in its own output and `--help`. The BCut consent rule is in the message `process` prints when a video has no subtitles (ask the user, and only with their agreement add `--asr bcut --allow-remote-asr`), where an Agent meets it; the flag itself still guards the upload.

- `download` drops share-tracking parameters (Bilibili's share and recommendation marks, YouTube's `si` and `feature`, `utm_*`) and keeps those that pick content (`p`, `t`).
- `process` uses a video processed before with the same frame settings as it is, since each run samples a new set of frames and would change a summary's links; `--force`, or a run asking for more (a missing transcript with `--asr`, slides, a region, a subtitle file), processes again. The desktop app always passes `--force`: there, processing is asked for on purpose.
- A layout check: a recording of five minutes or more with a camera and fewer than two screen pages gets a note naming `layout.jpg` and `--screen-region`, in the output and in `summary-context.md`.
- Pointed-at frames (removed 2026-10-29, see [Evidence for weaker chat AIs](chat-ai-evidence.md)): in a layout with a camera, a transcript line with pointing words and no representative frame within 10 s gets a frame in `frames/extra/` (one per 20 s, 30 at most), listed in the context with the words said. **Claude judgment:** the word list, the distances, and leaving out whole-screen recordings, whose screen pages already show what is pointed at; a heuristic, where a frame too many costs little. Tried on the maintainer's 41 processed videos without taking frames: "这个表" and "这个图" also hit 这个表达式 and 这个图案, and a bare 我们看 hit 我们看到一路走过来, so those forms were narrowed; after that most hits point at something, about five in a 100-minute lecture.
- An Agent writes `总结.draft.md` (`合集总结.draft.md`, `学习提纲.draft.md`) beside the file it becomes, and `summarize --import` with no file saves it and removes it, instead of a temporary file of its own that it had to delete.
- `collection show` and `list` give `overview_behind` and `guide_behind`, the videos whose summary changed after the overview or guide was written (by modification time); the GUI's collection page says so above the text.
