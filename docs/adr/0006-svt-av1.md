# ADR-0006: 压缩视频用 SVT-AV1

## 背景

- 压缩后分辨率不变、看不出画质差别（`MGT-01`）。
- 安装包里的 FFmpeg 是 LGPL 构建（[ADR-0005](0005-own-lgpl-ffmpeg.md)）。

## 决策

用 SVT-AV1 preset 8、CRF 40 重新编码，分辨率不变；几乎不动的画面降到每秒 10 帧。已经是 AV1、HEVC、VP9 的视频不动。具体做法见 [processing-design.md](../processing-design.md)「压缩」。

实测（VMAF，5 分钟片段）：1080p 屏幕录像剩 20%（每秒 10 帧，VMAF 96.8）；教室摄像机录像（H.264，1.75 Mbps）剩 59%（VMAF 94.7）。

## 备选方案

1. **x265**：也能压得小，但它是 GPL，LGPL 构建里没有。
2. **硬件编码**：要更多的库；摄像机画面的 VMAF 分数明显低。

## 影响

- SVT-AV1 一个编码就用满所有核，所以默认同时只压一个视频。
- 用 pip 或 uv 安装时用找到的 FFmpeg；它没有 libsvtav1 时，`compress` 说明原因。
