# ADR-0004: 屏幕页由 AutoSlides Extractor 找，本程序的规则兜底

## 背景

- 屏幕上出现过的每一页都要截到，同一页逐步出现的几步合成一页（`FRM-01`）。
- 本程序有自己的翻页规则（`media.screen_pages`、`page_rules.py`）。
- 多截的页可以去掉：网页 AI 会在「画面调整」里写不用的图（[routes-design.md](../routes-design.md)「画面调整和补截」）。

## 决策

1. 装了 AutoSlides Extractor 时由它找屏幕页；分割和小窗布局先把屏幕区域单独编码成视频给它；它的结果里逐步出现的几步由 `page_rules.merge_steps` 合成一页。
2. 它没装、失败或被关掉（`--no-extract-slides`、`AUTOSLIDES_EXTRACTOR=none`）时，用本程序的规则。
3. 它作为程序运行，不复制代码；不打进安装包，用户在设置里点了才下载它的免安装版。
4. 漏掉的画面由读全字幕的模型在「画面调整」里提补截，程序不按字幕自动补截。

## 备选方案

1. **只用本程序的规则**：一段 99 分钟的屏幕录像上，AutoSlides Extractor 找到 115 页，本程序的规则 88 页；多出的页里有三页是几秒内就翻过去的。
2. **把 AutoSlides Extractor 打进安装包**：每次发布多约 90 MB，还要附上 FFmpeg 7、Qt 6 的源码。
3. **bit-admin 的幻灯片分类器和检测器**：在本项目的画面上不准，把图表当成不是幻灯片，找不到被拍的投影。
4. **按字幕里的指向词（「这个图」「我们看」等）自动补截**：讲图论等话题时误触发，而且常截在画面出现之前。

## 影响

- 结果随机器上装没装它而变，所以测试关掉它（`tests/conftest.py` 的 `no_extractor`）。
- 界面上它的勾选框说明写总结不需要它；`tools` 找不到它时变灰并说明。
