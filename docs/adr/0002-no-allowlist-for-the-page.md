# ADR-0002: 页面和主进程之间不设白名单

## 背景

- 页面只能经 `window.va`（`preload.js`）找主进程（ARCHITECTURE.md 不变量 `A5`）。
- 用户本来就有命令行和内嵌终端（`APP-03`），能以自己的身份运行任何命令。
- 总结里的链接可能指向任何地方。

## 决策

主进程不按白名单过滤页面的请求：页面能让主进程运行任何命令行命令，`shell:open` 能打开任何路径。

页面本身照样受限：开着上下文隔离、沙箱和严格的 CSP；Markdown 用 DOMPurify 净化；`fs:read` 只读工作区里的文件。

## 备选方案

1. **按白名单限制页面能运行的命令和能打开的路径**：挡不住同一个用户本来就能做的事，每个新功能还都要去改白名单。

## 影响

- 页面里一旦跑了别人的脚本，就能运行命令，所以防线在页面这一侧：沙箱、CSP 和 DOMPurify 净化都不能放松。
