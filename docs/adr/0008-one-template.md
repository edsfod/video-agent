# ADR-0008: 所有写总结的方式共用一份模板，规则从三条原则推出

## 背景

- 几种写总结的方式要写出同一种总结（`SUM-02`）；用户能照着自带模板做自己的模板（`SUM-03`）。
- 总结要做到的事逐条列在 [summary-requirements.md](../summary-requirements.md)（`PRM-*`）。

## 决策

1. 一份规则，所有方式共用：`src/video_agent/prompts/summary.md`（`video-agent template` 打印），用中文。改规则先改 summary-requirements.md，再照它改模板；每条规则只写在一处。
2. 规则从三条原则推出，不针对某个视频出的毛病加特例：单元是唯一的正文，视图由程序从单元组合（[ADR-0013](0013-outlines-instead-of-a-linear-body.md)）；每句话按它说的是什么归类，先分前置部分和知识（`SUM-06`）；每个条目、每层关系都标明来源。
3. 规则不点名任何学科或视频类型；给模型的例子用占位符。
4. 自查清单写在模板里；网页 AI 的结尾提醒和复查要求引用它（`templates.checklist`）。

## 备选方案

1. **给模型的例子用真实视频的内容**：模型会把例子当成视频本身的内容。

## 影响

- 用户自己的模板带着自己的自查清单。
- 分阶段写总结按「标准」模板的节拆规则、组装成稿，所以只能用「标准」模板（[ADR-0010](0010-staged-through-agy.md)）。
- 新的总结结构先只由分阶段写出，别的方式暂时写现在的形式（`SUM-02`），这段时间里各方式写出的不是同一种总结。
- 和现有实现还不一致的地方：模板和 summary-design 的「规则」仍按「一个正文，两种视图」写，第二条原则仍是「按它做什么归类」。
