# 意图与需求

> 给谁看：参与设计和实现的人和 AI。回答：要解决什么、怎样算做成、范围和约束。各部分怎么做见 [design.md](design.md)。

## 要解决的问题

看一个视频（课堂录像、讲座、访谈、教程、新闻）很费时间，而且看完记不住。用户要的是一份能代替看视频的笔记：视频讲了什么、要照办的事、日后能用上的内容，每一点能回到视频的时间点，画面上的内容也在里面。

## 怎样算做成

### 拿到视频和字幕

1. 任何来源的视频都能处理：本地文件直接处理；给链接时用 yt-dlp 先下载，下载和处理是分开的两步。
2. 下载时一起存下网站的字幕；要登录才给的字幕（例如 B 站的 AI 字幕），能在程序里登录网站账号，把登录状态交给 yt-dlp 用。
3. 字幕先用已有的（视频内的字幕轨、旁边的字幕文件，名字不同的可以手动导入），没有时才用语音识别；音频上传到远程识别服务要用户同意。
4. 反复听错的名字和术语能改正：改正另存一份，原字幕不动，改正可以撤回；改正后的字幕用于此后的所有总结。

### 画面

5. 屏幕上出现过的每一页（幻灯片、代码、文档）都截到，用原始分辨率，一页一张，同一页逐步出现的几步合成一页；其余画面按间隔和场景变化抽取；写总结时能按时间补截。
6. 能导入一个放着课件图片的文件夹，代替截下的屏幕页，按时间表或画面对上时间。

### 总结

7. 总结让没看过视频的读者知道视频讲了什么、记住要照办的事、日后能用上视频的内容：分得清哪些是视频说的、哪些是视频引用别人的、哪些是总结者加的；每一点能回到视频的时间点；画面上的文字、表格、图表读进总结。具体要求见 [summary-requirements.md](summary-requirements.md)。
8. 几种写总结的方式写出同一种总结，都按用户选的模板：Agent 应用（按 skill）、分阶段（agy 命令行）、模型 API、网页 AI（复制材料或导出文件，DeepSeek 网页版全自动）。
9. 自带「标准」模板；用户可以照着它做自己的模板，选哪个模板写。
10. 同一个视频的每一版总结都保留，由用户决定用哪一版。
11. 几个相关的视频（一门课、一个系列、一个播放列表）组成合集，有合集总结和学习提纲；合集可以跟着播放列表下载新视频。

### 管理

12. 能压缩视频省空间：重新编码后分辨率不变、看不出画质差别。默认只压缩本程序下载的视频；用户从自己硬盘添加的要用户同意，因为会替换原文件。
13. 能一次删掉选中的视频和它的全部产物（字幕、画面、所有版本的总结、在合集里的位置）；本程序下载的视频文件一起删，用户自己添加的视频文件保留。

### 桌面程序

14. 桌面程序能完成以上全部操作；命令行工具也能，供 Agent 和批量处理用。
15. 下载或添加视频后默认自动处理（可以关）；没有字幕的本地视频先问是否用语音识别。
16. 有内嵌终端、托盘、任务队列和任务日志。

### 安装和更新

17. 三种装法，按需取用：安装包自带一切（命令行工具、yt-dlp、FFmpeg），装完就能用；命令行工具用 uv 安装，不需要 git；Agent 插件装进 Claude Code 或 Codex，桌面程序可以从本机的副本安装。
18. 桌面程序能检查更新、只下载变化的部分、静默重装；GitHub 访问不了时改走 GitHub API 或下载镜像；只接受签名有效的更新；设置、工作区和已装的插件跟着保留和更新。

### 隐私

19. 安装时先显示隐私说明和使用条款（`PRIVACY.md`），设置里随时能看。
20. API key 存在 Windows 凭据管理器里，任务日志从不记录 API key。

## 范围

- 只支持 Windows（用户 2026-10-27 定）。
- 许可证 AGPL-3.0-or-later；安装包里的 FFmpeg 按 LGPL，每次发布附上源码。
- 总结文章：计划中，见 [roadmap.md](roadmap.md)。
- 不做：常驻的 MCP 服务；某个平台专用的逻辑（例如雁课堂的归 AutoSlides）。

## 约束

### 边界

- 桌面程序和其他前端都调用命令行工具，自己不含处理媒体或写总结的逻辑。
- 命令行工具的核心不依赖任何模型服务商，也不依赖界面库；只有写总结的 `summarize` 在运行时才加载模型服务商。
- AutoSlides Extractor 和 yt-dlp 通过它们的命令行调用，不复制它们的代码。
- 保持通用：别的工具的文件夹布局只作为有名字的约定加手动导入支持，不内置。

### 视频和下载

- `process` 接受任何本地视频路径，从不下载；`download` 单独、可选。
- 不修改、不移动源视频。例外：`compress` 用核对过、确实更小的副本替换，`delete` 删除本程序下载的视频（见第 12、13 条）。产物都放进工作区。

### 字幕

- 先用已有的字幕，再用可替换的语音识别；命令行里音频只有加了 `--allow-remote-asr` 才上传到远程识别服务。

### 画面

- 代表画面跟着视频走：每个不同的页面和场景都要有，不设固定的少数几张；高上限只用来挡住失控，到了会说明。不认为编码关键帧和场景变化本身有意义。
- 先识别画面布局；屏幕旁边或里面有摄像头画面时，只在屏幕区域里按原始分辨率找翻页。
- 屏幕页装了 AutoSlides Extractor 时由它找（先裁出屏幕区域给它，同一页逐步出现的几步合成一页），否则用本程序自己的翻页规则；`--no-extract-slides` 或 `AUTOSLIDES_EXTRACTOR=none` 关掉它。

### 依赖

- yt-dlp 和 FFmpeg 是 Python 依赖；安装包自带 yt-dlp 和自己编译的 LGPL FFmpeg。`PATH` 上已有的优先。
- 不安装别的工具：缺什么就说缺什么、怎么指定。唯一的例外：用户在设置里点了，才从作者的发布页下载 AutoSlides Extractor 的免安装版。
