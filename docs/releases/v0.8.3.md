**改进：总结规则。** 对比 DeepSeek 网页版和 Gemini 写的同一节课，规则改了几处：

- 详细内容写成能快速扫读的笔记，不按讲话顺序逐句复述；每一部分用几句话、列表、表格还是步骤，由写的人按内容判断，不再每部分一个样。
- 可以补充视频以外有帮助的内容（背景、原理、定义、已知的更正），但每条以「补充：」开头，和讲者说的分开。
- 保留讲者的语气和分寸：讲者说「不建议」的，不写成「严禁」。
- 链接的画面要是讲到这一点时屏幕上的那一张。

在设置里改过「总结规则和模板」的，会看到「默认规则已更新」，可以对照新的默认规则合并，或者点「恢复默认」。

**修正：**

- 总结的「版本」一栏点「备注…」没有反应。现在会弹出一个框，填着这个版本原来的备注，改完按回车或点「保存」；留空就去掉备注。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.8.3.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.8.3/video_agent-0.8.3-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
