测试版。1.7.0 起多一种写总结的方式「分阶段（agy）」：经 Antigravity 命令行，把视频分成单元同时写，由程序检查、发回原对话修改。正式版用户收不到这个版本；设置里开着「接收测试版」时才会更新到它。

**新增：分阶段（agy）**

- 总结页选「分阶段（agy）」。先由一个对话读整段字幕，把视频分成单元（讲者围绕一点展开的一段）；每个单元交给一个对话同时写，它对着这一段的字幕和画面写；最后由第一个对话写要点、概要和需留意的事项。第 1 课（100 分钟）上约 13 分钟写完，成稿约 9.4 万字，长视频后半段也写得和前半段一样细。
- 程序检查每个单元：有没有整段讲话没写到、画面清单里的图是不是都判断过、链接对不对、时间在不在这一段里、几个单元是不是写了同一件事；只把查出的问题发回写这个单元的对话去改，最多两轮。
- 写单元的对话只能看图，不能运行命令，读不了视频文件夹以外的文件。
- 屏幕上的小字：写的人打开的单张图放大了 2 倍；读不准、和内容有关的，它可以请求把那一块再放大。从图上读出、没有放大核对过的长公式，程序在后面标「（AI 未核对）」，点开旁边的图可以自己看。
- 「模型」是分单元和写第一稿用的，默认 Gemini 3.8 Flash (High)；「修改轮」另选，默认 Medium。两个都可以从 `agy models` 的列表里选，或者自己填。
- 每一版用掉的 token（调用次数、读入、缓存命中、输出、其中思考）记在这一版的备注里，版本列表里能看到。
- 需要装 Antigravity 命令行（`winget install Google.AntigravityCLI`），它用 Antigravity 桌面版的登录和额度。没有找到 `agy` 时这一项是灰的。
- 只能用自带的「标准」模板；这种方式不收「对总结的要求」。合集总结和学习提纲暂时不能用这一项。
- 任务停止或中断后，再点一次生成总结，会接着写没写完的部分。

**去掉：Antigravity 桌面版**

总结页不再有「Antigravity」（交给运行中的 Antigravity 桌面版写）。它和分阶段用的是同一个模型，但系统提示和工具我们控制不了，一份总结要读入几百万 token；要用 Gemini，选「分阶段（agy）」。设置里「其他 Agent」的 Antigravity CLI 预设保留。

**代码改动：**

- 命令行：`summarize --staged`（`staged.py` 流程、检查、合并和组装，`staged_agy.py` agy 通道和只许读文件的钩子 `_staged-gate`，`staged_prompts.py` 各步的提示），可选 `--model`、`--fix-model`、`--restart`；状态存在视频文件夹的 `staged/` 里。版本记录加了 `usage`，`versions --json` 带出。
- 桌面程序：总结页加「分阶段（agy）」和修改轮的模型，去掉 Antigravity 桌面版（`antigravity.js`）。
- 文档：新增 `docs/design/staged.md`；`routes.md` 写明分阶段接哪些通道。
- 测试：合并、程序标记、无用画面的链接、单元表、组装要点、agy 的用量记账和钩子，以及用照脚本回答的假通道跑完整个流程。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.7.0-beta.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.7.0-beta/video_agent-1.7.0b0-py3-none-any.whl
  ```

  Python 的版本号写法不同，所以文件名里是 `1.7.0b0`。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 1.6.0 相同。
