1.1.0 主要是代码整理，另外有两处操作上的改动和一处修复。

**改动：**

- 在左边再点一次已经打开的视频或合集，就回到首页。打开的是合集里的某一集时，点合集那一行先回到合集页。
- 切到「终端」不再自动打开终端，点「启动终端」才打开；打开后按钮变成「新建终端」。

**修复：** 在列表对话框里选择下载整个列表后，链接框里的链接没有清掉。

**其他：**

- 设置里指定了别的 Video Agent 命令行、它和桌面程序的版本对不上时，左边会提示，可以清空设置改用安装包自带的。为此命令行的 `tools --json` 多了 `json_version` 一项，合集的 `collection.json` 也记下了格式版本；旧的合集照常能用。

**代码整理**（用起来没有变化，代码按原样搬动，没有改写逻辑）：

- 命令行用 `--json` 输出的每种结果，以及 `manifest.json` 和 `collection.json`，都有了明确的类型定义（`contract.py`）。生成这些数据的 Python 代码由 mypy 检查；测试里命令行打印的每一条 JSON 都按类型核对，多一个或少一个字段都会报错。桌面程序用的类型文件（`cli-types.d.ts`）由它自动生成。
- 桌面程序的 JavaScript 改由 TypeScript 做类型检查（不编译，代码照旧是 JavaScript），推送前和 CI 里都会跑。检查出的唯一一个 bug 就是上面修复的那个。
- 原来 792 行的 `summarize.py` 按职责拆成几个文件：调用模型 API、挑选画面、导入网页 AI 写的总结、给网页 AI 打包材料、合集总结。Anthropic 和 OpenAI 兼容接口改成同一个接口下的两种实现，以后加新的服务商只需加一处。
- 命令行各子命令改为各自绑定处理函数，不再是一长串 `if`。
- 桌面程序的界面代码（原来一个 2,280 行的 `app.js`）按页面拆成 14 个模块，主进程（原来 987 行的 `main.js`）按职责拆成 8 个模块。
- 判断屏幕翻页、合并相似页面的规则单独放进 `page_rules.py`，并加了不用视频、用合成图片就能跑的测试。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.1.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.1.0/video_agent-1.1.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
