**新增：账号列表。** 设置里原来的「哔哩哔哩账号」改成「账号」，有哔哩哔哩、抖音、YouTube 三个，可以用箭头调整顺序，不用的可以隐藏。下载哪个网站的视频，就把哪个网站的登录状态交给 yt-dlp。

- 哔哩哔哩：和以前一样，登录后字幕跟着视频一起下载；原来的登录还在。
- 抖音：yt-dlp 要先有抖音网页给的 Cookie 才能下载，不一定要登录，点「打开」，网页加载完关掉即可。
- YouTube：一般的视频和字幕不用登录；年龄限制、会员视频，以及 YouTube 要求“登录以确认你不是机器人”时才需要。
- 「从浏览器导入…」：一键读取浏览器里的登录状态（Firefox 可以直接读；Edge 要先完全关掉；新版 Chrome 加密了 Cookie，读不出来），或者按里面的步骤用扩展导出 cookies.txt 再导入。只留这个网站的 Cookie。
- 登录窗口是单独的窗口，可以单独最小化。

**新增：总结时选模型和思考强度。** 总结页的方式下面有「模型」和「思考强度」两个下拉框，每种方式各记各的，合集页用同一种方式时也用这里选的。

- 模型列表从各自那里读，不消耗 token：Claude Code（别名和完整型号）、Codex（它下载的模型目录）、pi、Hermes Agent、DeepSeek Harness（它配置里的模型）、模型 API（服务商的模型列表）。列表里没有的，选「自定义…」自己填。
- 思考强度：Claude Code、Codex、pi、Hermes Agent、模型 API 可以选；DeepSeek Harness 没有这个选项。选「默认」时用它们自己的设置。
- 「复制材料」挪到了第一个。所有下拉框换成和输入框一样的样式。

**新增：把 skill 复制给其他 Agent。** 设置 → Agent 插件里，「复制到 pi」「复制到 Hermes Agent」「复制到 DeepSeek Harness」把 skill 文件夹复制到它们读 skill 的地方，「复制到其他文件夹…」给别的 Agent 用。程序更新后会自动换成新版本；选的文件夹里已经有别的 `video-agent` 文件夹时不会覆盖它。

**改进：压缩。**

- 「已压缩」单独记下来：「处理」页的按钮会显示「已压缩」「不用压缩」或「压缩过，没变小」，合集页每集也标出来。
- 「压缩各集」先检查一遍，只把还需要压缩的排进去，并说明跳过了几集。
- 设置 → 同时运行的任务数里可以设压缩，默认一次一个（一个压缩已经用上所有核心）。
- 停止正在进行的压缩后，不再在视频旁边留下压了一半的隐藏文件。

**改进：任务和更新。**

- 任务面板里可以勾选多个任务一起停止，也可以「全部停止」。
- 更新下载太慢时（15 秒后平均不到约 300 KB/s，照这个速度还要一分钟以上），自动换下一个镜像。
- 设置里加了「接收测试版」：勾上后「检查更新」也会找测试版。装了测试版的默认勾选。

**修正：**

- 启动时默认选中第一个合集；侧边栏启动时先闪出所有视频再收起。现在启动时什么都不选，合集读好后才显示列表。
- 任务结束得多时，合集列表偶尔读取失败，合集被清空、各集全部跑到「视频」下面（0.9.2-beta 出现过）。现在一次只读一份，读失败时保留原来的合集，几秒后再读。
- 关闭设置要卡一下（每次都重新应用一遍主题）。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.9.2.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.9.2/video_agent-0.9.2-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。新命令 `video-agent models` 列出模型 API 的模型，`summarize --effort` 设思考强度。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
