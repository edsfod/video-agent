**新增：压缩视频。** 用 AV1 重新编码，分辨率不变，看不出画质差别：屏幕录像（画面基本不动）降到每秒 10 帧，大约剩原来的五分之一；摄像头画面大约剩一半多。已经是 AV1、HEVC 的视频（比如 B 站的）不再压缩。压好的文件先核对时长，确实变小了才替换原文件，路径不变，处理结果和总结照常可用。设置 → 压缩视频：「压缩下载的视频」默认开，下载完先压缩再处理；「也压缩从本地添加的视频」默认关，因为会替换你电脑上的原文件。「处理」页也可以单独压缩一个视频。

**新增：导入字幕和课件。**

- 「字幕」页的「导入字幕…」可以选任何名字的 SRT 或 WebVTT 文件。
- 「画面」页的「导入课件…」可以选一个放着课件图片的文件夹；有时间表的按时间表，没有的按画面对上时间，之后用它代替截下的屏幕页。[AutoSlides](https://github.com/bit-admin/Yanhekt-AutoSlides) 下载的屏幕录像（`screen_….mp4`）会自动用上旁边的 `slides_…` 文件夹。

**改进：本地视频和必剪。** 从本地添加的视频会马上处理，旁边有同名字幕的直接读进来；没有字幕的先问你：用必剪转录（会上传音轨）、只处理画面，还是先不处理。下载的视频没有字幕时默认用必剪转录，不用再处理一遍；「处理」页可以关掉。

**改进：网页 AI 写的总结。**

- 材料里的字幕按当时屏幕上的那一页分段，每段开头写着那一页的画面，链接的画面更容易对上讲到的内容。
- 材料最后再提醒一遍最容易被忽略的几条规则；要求把整篇放进一个 Markdown 代码块，方便复制。
- 「字幕改正」作为模板最后一节，附上格式。
- 网页 AI 可以写「补截」链接（例如 `[画面](补截:00:12:34)`），导入时自动在那个时间截图。
- 同一页逐行出现的几步合成一页，留最完整的那张，总结里少了大量重复的屏幕页。

**改进：**

- 「其他 Agent」可以同时勾选多个，每个都是一种总结方式；没选时也显示，并提示去设置里选。
- 侧边栏只列合集，各集在合集页里打开；视频页顶部可以点回所在的合集。
- 处理结果的文件夹名保留中文，旧文件夹第一次用到时自动改名。

**修正：**

- 版本的「备注…」点了没反应。
- 合集补上列表链接、检查新视频时，已经下载过的各集又全部排进处理。
- 状态文字太长时把按钮挤到换行；点开的画面会被整张选中。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.9.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.9.0/video_agent-0.9.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`，这一版新增 `SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`）。
