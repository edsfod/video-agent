1.0.0 的功能和 0.9.3 相同，另外补上了许可证和隐私说明。

**新增：许可证、隐私和使用须知。**

- 安装时先显示一页说明，写的是：程序按什么许可证发布，什么时候联网、把什么发给谁，下载的内容怎么用，以及总结可能出错。点「我同意」后继续安装。更新时不显示这一页。
- 设置里多了「关于」一节：显示版本和许可证，可以查看隐私和使用须知，也可以打开许可证全文和第三方组件的许可证。
- 这份说明也放在安装文件夹里（`PRIVACY.txt`）和源码里（`PRIVACY.md`）。

**改进：** 设置 → 总结模板 →「查看 skill」上方的说明改成和新版 skill 一致。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.0.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.0.0/video_agent-1.0.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
