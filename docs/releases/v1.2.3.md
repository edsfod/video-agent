1.2.3 修复「DeepSeek 网页」卡住和读不到回答的问题，可以同时跑几个 DeepSeek 总结，并让网页 AI 少链没用的画面。

**修复：**

- DeepSeek 写完了，程序却一直等着、不导入。原因是 DeepSeek 页面不会一直留着前面的回答：到第三轮时，第一轮的回答已经从页面上去掉了，回答的数目没有变多，程序就以为还没写完。现在发送前先给页面上已有的回答做记号，没有记号的那个就是新回答。
- 发出后一直显示「正在分析图片」、始终不开始写。查下来是那次发送根本没到 DeepSeek 服务器。现在发出 3 分钟还没开始写，就重新载入对话、重新附图再发，最多 3 次；正常情况下几十张图几秒内就开始写。

**改动：**

- 「DeepSeek 网页」的总结可以同时跑几个：每个任务开一个自己的 DeepSeek 窗口，登录共用；在一个窗口里登录后，其他停在登录页的窗口会自动刷新。同时跑几个按「设置」里「总结」的数目算（默认 2），以前 DeepSeek 只能一次一个。DeepSeek 提示「并发请求过多」时，按服务器繁忙处理，等一会儿再发。
- 网页 AI 复查时，要对总结里链接的每张图写一行：图上有、字幕里没有的是什么。写「无」的（图上的字就是讲者说的话的标题卡、讲者特写、素材画面），程序去掉这个链接，以后也不再把这张图发给它；链接了却没写的，下一轮点名要它补上。以前提示里虽然写了素材、讲者特写不链接，它照样链，复查几轮下来链得反而更多。
- 同一次多轮里，后一轮的总结覆盖前一轮，不再一轮存一个版本：原来没有总结时，覆盖当前总结；旁边已有总结时，只留一个版本，备注写到第几轮。新开一次总结仍然另存，不会覆盖上次的结果。

**代码改动：**

- `deepseek.js` 改成一个对话一个窗口（`conversation()`），窗口用完留给下一个任务；回答写完的判断改为找没有记号的最后一个回答块；发出后迟迟不开始写时整条重发。`chat-rounds.js` 每个任务用自己的对话，停止只停这一个任务。任务队列去掉了 DeepSeek 单独限 1 个的规则，按总结算。
- 命令行 `summary_review.py` 读复查里的「画面：」各行，去掉写「无」的链接，并检查链接了却没写的图；`importer.py` 把去掉的图记为不用，后一轮的回答覆盖前一轮的文件（`versions.py` 新增 `overwrite`）。
- 测试：模拟 DeepSeek 页面加上一次卡在「正在分析图片」、每来一个新回答就去掉最早的一个；新增复查里「画面：」各行的测试和后一轮覆盖前一轮的测试。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.2.3.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.2.3/video_agent-1.2.3-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
