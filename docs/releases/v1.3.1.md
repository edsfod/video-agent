1.3.1 修复「DeepSeek 网页」多轮停不下来的又一个原因，并让网页 AI 看过却没用上的画面自动去掉。

**修复：**

- 程序读 DeepSeek 的回答时会漏掉最后一两行。DeepSeek 写完、发送按钮恢复以后，最后几行要稍晚一点才出现在页面上，程序读得太早。拿一次 6 轮的记录对比：复查最后几行写的是几张图的「画面：」说明，程序每轮都没读到，就每轮报「这些图没有写说明」，DeepSeek 每轮又去「补上」，就这样一直到第 6 轮；其实稿子从第 4 轮起一个字都没变。现在写完后隔一会儿再读一次，两次一样才算读完。

**改动：**

- 发给网页 AI 的图，它看过、稿子里却没有链接的，导入时从新的一套画面里去掉，不再要它一张张写「不用」。以前它只点名一部分没用的图，剩下的讲者特写、电视剧画面一直留着。没发给过它的图照旧保留，等以后有机会再判断。提示里也写明了：有用的图都要链接到讲到它的地方。后面某一轮又链上的图会回到那一套里，原来的各套也都还在，可以随时换回去。

**代码改动：**

- `deepseek.js` 判断写完以后，每隔 1.5 秒再读一次回答，直到前后两次相同。
- 命令行 `packing.py` 打包时把这一轮发出的画面（拼在总图里的屏幕页也算）记进 `picture-review.json`；`importer.py` 导入时把其中没被链接的从新的一套里去掉。
- 测试：模拟 DeepSeek 页面让回答的最后一行晚一秒出现；新增发过但没链接的图被去掉的测试。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.3.1.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.3.1/video_agent-1.3.1-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
