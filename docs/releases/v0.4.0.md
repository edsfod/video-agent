**新增：合集。** 几个相关的视频（一门课、一个系列、一个播放列表）可以放进一个合集：侧栏「合集」→「新建」，或在视频页点「加入合集…」。合集页面列出每一集处理和总结到了哪一步，可以一次「处理未处理的」「总结没总结的」；某一集几乎没有内容（比如没上课的空教室），可以跳过并写明原因。各集都有总结后，再「生成合集总结」（各集都提到的需留意事项、各集一览、主线）或「生成学习提纲」（按主题的重点，带答案的自测题），四种总结方式都能用，选「复制材料」时可以把网页 AI 写好的导入回来。

**新增：整理版字幕。** 字幕里反复识别错的名字、术语，在「字幕」页的「改正错字」里填上错的写法和正确写法，就会另存一份整理版，之后的总结都用它；原始字幕保留不动，勾「看原始字幕」可以对照。合集里可以设一份各集共用的术语改正，之后加入或处理的视频也会套用。Agent 总结时也会先把明显的错字改掉。

已装 0.2.0 或 0.3.0 的，在「设置 → 更新」里就能更新；设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.4.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.4.0/video_agent-0.4.0-py3-none-any.whl
  ```

  新命令：`video-agent fix`（整理版字幕）和 `video-agent collection`（合集）；`summarize --collection` 写合集总结，加 `--guide` 写学习提纲；`download --playlist --collection` 下载播放列表时直接放进一个合集。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
