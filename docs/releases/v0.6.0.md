**新增：跟踪连载合集。** 下载 B 站合集、播放列表这类链接时，弹框里默认勾着「跟踪这个列表」。以后出了新视频，在合集页点「检查新视频」，只下载还没有的那几集，按顺序排在最后；也可以打开「程序开着时每 6 小时自动检查」（默认关，因为可能自动开始大下载）。新视频照常按「下载完自动处理」的设置处理。以前下过的合集，在合集页「跟踪的列表」里填上链接即可，第一次检查会认出已经下好的视频，不会重下。后台检查下完不会把你从当前页面拉走。

**修正：更新只下载变化的部分。** 更新本该只下载和旧版不同的几 MB，但 GitHub 不接受一次要多段数据的请求，程序每次都退回下载整个安装包（约 160 MB）。现在改成一次要一段。下载更新的是正在运行的版本，所以从 0.6.0 再往后的更新才会变小；这一次从旧版升级仍是整包下载。

已装 0.2.0 到 0.5.0 的，在「设置 → 更新」里就能更新；设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.6.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.6.0/video_agent-0.6.0-py3-none-any.whl
  ```

  新命令：`download --playlist --collection 名字 --follow` 下载并跟踪列表，`collection update 名字` 只下载新视频，`collection follow 名字 链接` 给已有的合集补上列表，`collection unfollow` 取消跟踪。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
