**改进：必剪转录重写，更快、更稳。** 没有字幕时用必剪（B 站的语音识别）转录的那部分，按这个项目的用法重新写了：

- 音频分块同时上传：一节 98 分钟的课（37 MB 音频）上传从约 11 秒降到约 5 秒。
- 短视频不再白等：结果从 1 秒起开始查，一段 90 秒的片段 5 秒左右就有字幕。
- 进度只在排队、识别中、完成时各说一次，不再每 10 秒刷一行。
- B 站限流时（返回 412 或 429）会等几分钟再试，并在进度里说明，不会直接报错。
- 等待时间按音频长度来定，不再一律等两个小时；必剪返回的空白句子不会写进字幕。

用法不变：处理页勾选「没有字幕时，用必剪（B 站）转录」，或命令行加 `--asr bcut --allow-remote-asr`；每次都要你明确同意上传音频。

从 0.6.2 更新到这一版，只下载变化的部分，相近的部分合并成一次请求；从更早的版本更新仍按原来的方式下载。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.7.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.7.0/video_agent-0.7.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
