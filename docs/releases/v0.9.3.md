**新增：几份总结模板并存，总结时选用哪一份。** 模板是总结的规则和格式。总结页上多了「模板」下拉框，四种总结方式和「复制材料」都按选中的写，合集总结和学习提纲也用它。

- 自带两份：「标准」是原来的写法；「命题分析」先列元信息（类型、讲者、范围，以及点名、作业、考核和评分标准、课程要求等「需留意」的事项），再把视频里的说法拆成编号的命题，标出事实、观点、推断、引用，画出论证的主线，每条命题写清主语、范围和条件，有歧义时列出几种读法。
- 设置 → 总结模板：可以编辑自带的（更新不会覆盖你改过的，自带的有改动时会提示你对比），也可以照着任意一份新建、起个名字，改成你自己的写法，不要了可以删除。
- 以前改过总结规则的，改过的那份成为你的「标准」；和自带某一份一字不差的，直接换成那一份。

**改进：Agent 少记几步，程序多做几步。** skill 只留下命令怎么用，原来要 Agent 记着做的事改由程序来做：

- 下载时自动去掉分享链接里的跟踪参数（B 站的 `vd_source`、`spm_id_from` 等，YouTube 的 `si`），`?p=2` 这类选分集的参数保留。
- 已经处理过的视频再处理时直接用上次的结果，免得画面重新抽一遍、总结里的图片链接对不上；要重做时加 `--force`。在桌面程序里点「处理」照旧重新处理。
- 有摄像头的视频，讲者说「如图」「看这个」「这张表」而附近没有画面时，自动补截一张，并附上讲者的原话。
- 五分钟以上、有摄像头、却几乎没截到屏幕页的视频，会提示布局可能认错了，并说明怎么手动指定屏幕区域。
- Agent 写好的总结先存成旁边的 `总结.draft.md`，再由 `summarize --import` 保存并删掉草稿，不再自己建、自己删临时文件。
- 合集里某一集的总结在合集总结或学习提纲写好之后改过，合集页会在正文上方提示是哪几集，可以重新生成。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.9.3.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.9.3/video_agent-0.9.3-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。新命令 `video-agent template --list`、`template <名字> --use` 列出和选定总结模板，`summarize` 和 `pack` 加 `--template <名字>` 只这一次换用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
