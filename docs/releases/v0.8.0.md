**新增：总结不会再被覆盖。** 已经有总结时，再生成或导入的新总结会另存为一个版本，原来的不动。在「总结」页上方的「版本」里可以切换查看每个版本（写明时间、用什么写的、备注），自己决定要不要「设为当前」，也可以写备注或删除。换成别的版本时，原来那份也留作一个版本。Claude Code、Codex 写总结时同样如此；就算它们直接改了文件，程序在开始前也已经存了一份。合集总结和学习提纲也一样不会被覆盖。

**改进：网页 AI 写的总结导入得更好。**

- 导入时可以写备注（比如用的是哪个模型），也可以选是否直接设为当前总结（默认不设）。
- Gemini、ChatGPT 网页版会把总结里的画面链接改成搜索链接或它们自己的地址，导致点不开；现在导入时会自动改回来，「打开视频」链接也会补上。
- 网页 AI 没法自己整理字幕的错字：现在材料里会请它在总结最后列一节「字幕改正」，导入时程序照着整理字幕（原字幕保留），再把这一节从总结里去掉。

**其他：** README 的截图换成了现在的界面。命令行新增 `video-agent versions`，查看和切换总结的各个版本；`summarize --import` 多了 `--note`、`--source`，`--make-current` 表示让新总结直接成为当前总结。

从 0.6.2 及以后的版本更新，只下载变化的部分；设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.8.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.8.0/video_agent-0.8.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
