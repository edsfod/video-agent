**这是测试版。** 程序里的「检查更新」不会提示它，要从本页下载安装包装上。正式的 0.9.2 发布后，它会照常提示更新。有三件事需要用自己的账号试一下，结果在群里或 issue 里说一声：

- 设置 → 账号 → YouTube 点「登录」，Google 账号能不能登上；
- 设置 → 账号 → 抖音点「打开」，网页加载完关掉，之后能不能下载抖音视频；
- 用 DeepSeek Harness 写总结时填一个模型，看它是不是用了这个模型。

**新增：账号列表。** 设置里原来的「哔哩哔哩账号」改成「账号」，有哔哩哔哩、抖音、YouTube 三个，可以用箭头调整顺序，不用的可以隐藏。下载哪个网站的视频，就把哪个网站的登录状态交给 yt-dlp。

- 哔哩哔哩：和以前一样，登录后字幕跟着视频一起下载；原来的登录还在。
- 抖音：yt-dlp 要先有抖音网页给的 Cookie 才能下载，不一定要登录，打开一次网页就行。
- YouTube：一般的视频和字幕不用登录；年龄限制、会员视频，以及 YouTube 要求“登录以确认你不是机器人”时才需要。Google 可能不让在程序里登录，那就从浏览器导出 cookies.txt，点「导入 cookies.txt…」导进来。每个网站都可以这样导入，只留这个网站的 Cookie。

**新增：每种总结方式都能选模型。** 总结页的方式下面多了「模型」，每种方式各记各的，留空就用它自己的默认模型；合集页用同一种方式时也用这个模型。Claude Code、Codex、模型 API、pi、Hermes Agent、DeepSeek Harness 都可以选；自己填的命令里写 `{model}` 的也可以。总结的版本里会记下用的是哪个模型。「复制材料」挪到了第一个。

**新增：把 skill 复制给其他 Agent。** 设置 → Agent 插件里，「复制到 pi」「复制到 Hermes Agent」「复制到 DeepSeek Harness」把 skill 文件夹复制到它们读 skill 的地方，「复制到其他文件夹…」给别的 Agent 用；之后在这些 Agent 里直接说“总结这个视频”即可。程序更新后会自动换成新版本。选的文件夹里已经有别的 `video-agent` 文件夹时不会覆盖它。

**改进：任务。**

- 任务面板里排队中、运行中的任务可以勾选，「停止所选」一起停止，「全部停止」停止所有任务。
- 设置 → 同时运行的任务数里可以设压缩。一个压缩已经用上所有核心，同时压几个总共快不了多少，所以默认还是一次一个。
- 更新下载得太慢时（15 秒后平均不到约 300 KB/s，照这个速度还要一分钟以上），自动换下一个镜像；最后一个源再慢也会下完。从这一版再往后更新时才用得上。

**修正：** 停止正在进行的压缩后，视频旁边会留下一个压了一半的隐藏文件（`.视频名.xxxxxxxx.part.mp4`）。现在停止时会删掉它，再压缩同一个视频前也会清掉以前留下的。原视频一直不受影响。

- **桌面程序**：下载 `Video-Agent-Setup-0.9.2-beta.exe`，直接运行即可覆盖旧版本，设置和工作区都保留。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.9.2-beta/video_agent-0.9.2b0-py3-none-any.whl
  ```

  Python 的版本号写法不同，所以文件名里是 `0.9.2b0`。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
