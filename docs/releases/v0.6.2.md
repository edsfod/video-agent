**改进：更新下载更快。** 0.6.0 起更新只下载变化的部分（约 9 MB），但它把变化的部分拆成一百多次请求逐个下载，每次请求都要等 GitHub 跳转和往返，结果比下载整个安装包还慢。现在相隔不远的部分合并成一次请求，多下几 MB、少等一百多次往返；从 0.6.0 到 0.6.1 那样的更新，按实测数据算会从约 77 秒降到 10 秒以内。下载更新的是正在运行的版本，所以这次升级到 0.6.2 还是原来的速度，再往后的更新才会变快。

**改进：「设置 → 更新」写明上次什么时候检查过。** 不再只说「已经是最新」，而是写「上次检查更新：今天 14:33（经 GitHub），没有更新的版本」，或「当时发现新版本 x.y.z」；重启程序后也记得。

已装旧版的，在「设置 → 更新」里就能更新；设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.6.2.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.6.2/video_agent-0.6.2-py3-none-any.whl
  ```

  命令行和 0.6.1 相同。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
