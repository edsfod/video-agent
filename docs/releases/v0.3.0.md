**新增：任务队列。** 下载、处理、总结不再一次只能做一件：可以一边处理一个视频一边下载另一个，任务多了就排队。左下角「任务」能看到每个任务的进度和输出，可以停止或重试。默认同时下载 3 个、处理 1 个、总结 2 个，可在设置里改；同一个视频的处理和总结不会同时进行，同样的任务不会重复排队。

**新增：B 站字幕跟着视频一起下载。** 在「设置 → 哔哩哔哩账号」里登录一次（程序自己的登录窗口，扫码即可），之后下载 B 站视频会把字幕（包括 AI 字幕）一起存下来。下载好的视频默认自动排进处理，字幕直接用上，不必再用必剪转录（左上角「下载完自动处理」可以关掉）。登录状态只存在本机、加密保存，只在下载 B 站视频时交给 yt-dlp。

**新增：屏幕页。** 处理时会识别画面布局：讲者摄像头和屏幕拼在一起时，只看屏幕那一块，按原始分辨率截下出现过的每一页幻灯片、代码和文档。布局画在 `layout.jpg` 上；认错了，可以在「处理」页的图上拖出屏幕区域重新处理。重复的页会合并：同一页上新出现的内容只留最完整的那张，滚动、切回已看过的窗口、一闪而过的画面不再各算一页；页数按视频长度自动调整（每小时约 15 到 75 页）。整幅画面也不再固定只留 36 张。

**新增：网页 AI 的往返。** 「复制材料」旁多了「导出 zip」：提示词、所有屏幕页和画面，以及每张拼了 4 页的总图，交给网页上的聊天 AI；写好后用「导入总结」粘贴或选文件存回来，画面链接照样能点开。

**新增：自己的总结规则。** 「设置 → 总结规则和模板」里点「编辑」，可以改成你自己的写法，几种总结方式都按它写；更新程序不会覆盖它，默认规则有改动时会提示对比。Agent 的 skill 流程可以查看，不能改。

**改进：**

- 总结默认写透：「详细内容」按视频自己的结构逐段写，篇幅跟着视频的信息量走，要短时再说。
- 用模型 API 总结时会发送所有屏幕页（页数多时拼成总图），默认最多 60 张图（原来 40）。
- 总结里的视频名不再带下载工具替换出来的 `⧸` 和转义符号；超过一小时的时长写成 `1:37:09`。新下载的视频文件名里，标题中的 `/` 换成 `_`。

**许可：** 安装包里的 FFmpeg 换成了自己编译的 LGPL 版（FFmpeg 9.0.2，带 dav1d 解码 AV1），不再附带 GPL 版。本页附有它的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），编译脚本在源码仓库的 `packaging/ffmpeg/build.sh`。安装目录里新增 `THIRD-PARTY-NOTICES.txt`，列出所有附带的第三方组件和它们的许可证；界面配色取自 [AutoSlides](https://github.com/bit-admin/Yanhekt-AutoSlides)（Apache 2.0）。

已装 0.2.0 的，在「设置 → 更新」里就能更新；设置和工作区都保留。

- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.3.0/video_agent-0.3.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。
