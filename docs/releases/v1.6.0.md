1.6.0 起，总结不再有「时间线」一节；「要点」每条写时间段，编号能点，画面由程序从详细内容带过来，在总结页显示成一排小标签。

**改动：**

- 去掉「时间线」：详细内容按视频先后分段、写了时间范围，要点按时间指向这些段，时间线和它们重复。
- 要点：
  - 模型每条写时间段（`` `00:12:00`–`00:15:30` ``）、一句话和编号，不再写画面链接。
  - 保存时，程序把要点里的编号换成跳到详细内容那一条的链接，再把这些条目在详细内容里链接的画面带到这一行末尾；条目自己没有画面时，取直接在它下面的前提或步骤的画面，同一张图只带一次；网页 AI 按 `补截:` 补截的画面也算。画面只链接在正文的命题上，所以要点上的图和正文对得上。
  - 桌面程序把这些画面收到这一条下面，显示成一排小标签，点了打开大图。
  - 要点可以写成编号列表，也可以有嵌套的子项。
- 只对带着「主线与单元」标记的模板这样做，自带的「标准」带着。你改过的「标准」副本照旧保留，设置里会提示自带模板有更新。

**修复：**

- 检查「要点一条都没指到的段」时只认粗体编号（`**P3**`），正文里的 `P2P` 这类词不再被当成编号。
- 说明文字里有方括号的画面链接也能认出来。

**代码改动：**

- 命令行：`forest.py` 给要点加编号链接和画面，导入和 `summarize` 保存时运行；`summary_review.py` 的编号只认粗体；`prompts/summary.md` 去掉时间线，要点改写时间段。
- 桌面程序：总结页把要点行末的画面收成小标签。
- 安装包里的 FFmpeg 重新编译过，版本不变（FFmpeg 9.0.2、dav1d 1.5.4、SVT-AV1 4.2.0）；SVT-AV1 不再做链接时优化，压缩的速度和结果不变。
- 构建：CI 编 FFmpeg 时经过 ccache，dav1d、SVT-AV1 单独缓存。
- 文档和写法检查：删掉已并入新文档的旧归档，写法检查覆盖无扩展名的脚本和块注释。
- 测试：要点的链接和画面（编号列表、嵌套子项、只认粗体编号）。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.6.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.6.0/video_agent-1.6.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`）。源码包与 0.9.0 相同，编译命令有改动。
