1.3.0 把总结用的画面分成几套，存成一棵树：网页 AI 筛掉的图可以找回来，也可以先让一个 AI 筛、再换另一个 AI 接着写。

**改动：**

- 每个视频的画面分成几套。处理得到的全部是一套；网页 AI 每轮筛掉没用的、复查里写「无」的，你在「画面」页手动去掉或放回的，都在当时用的那套下面另存成新的一套，记下是谁改的、第几轮、哪天。图片文件只有一份，每套只记哪些图。
- 以后的总结，不管哪种方式，都只拿其中一套。默认是最近一次改出来的那套，「总结」页上会写明用的是哪套。在「画面」页可以换成任意一套，比如先让便宜的 AI 筛几轮，再换好的 AI 接着写；觉得筛错了，就换回上面的某一套重来。
- 「画面」页默认显示「总结」页正在看的那份总结用的那套，不用的图收起来不显示；勾「显示不用的」可以看到，并点「恢复」放回。鼠标移到图上有「不用」按钮。
- 修正：以前网页 AI 说「不用」的图会永远不再给任何总结方式，后一轮又链上了也收不回来，「画面」页上却还显示着全部。拿一个视频看，104 张图里有 84 张记成了不用，其中有一张法条页，最后一轮还链着它、说明了图上有字幕没念的日期。现在最新一稿链着的图一律算在那一套里。
- 修正：网页 AI 要补截时截的候选，以前会一直留在后面的材料里，和原来的画面挤名额；现在候选只在被链上以后才算进那一套。
- 每个总结版本都记下自己是用哪套画面写的。
- 原来的「不用」名单会自动变成第一套「以前去掉的画面」。

**代码改动：**

- 命令行新增 `pictures.py`（画面集合的树，存在视频文件夹的 `pictures.json`）和 `video-agent pictures` 命令：列出各套，`--use` 换用，`--drop`、`--restore`（可加 `--from`）手动去掉或放回。打包、`summary-context.md` 和模型 API 的材料都按正在用的那套挑图；`importer.py` 每轮导入时从当前那套长出新的一套；`versions.py` 给每个版本记下 `pictures`；`picture_review.py` 只管补截的候选。
- 桌面程序的「画面」页加了选择画面集合的下拉、「以后的总结用这套」、「显示不用的」和每张图的「不用」「恢复」按钮；「总结」页加了一行说明用哪套画面。
- 测试：新增画面集合的树的测试（筛掉、链回来、换用、手动去掉和恢复）和「画面」页的桌面程序测试。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.3.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.3.0/video_agent-1.3.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
