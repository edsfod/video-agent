1.4.1 重写了「标准」模板的总结规则：先列出规则要做到的每一件事，再写成一份每条只出现一次的规则；并修掉了在两节课上重跑时发现的几处问题。

**改动：**

- 「标准」模板的规则全部改用中文，每条只写一次。以前同一条规则分别写在英文规则、模板各节的说明、网页 AI 的结尾提醒和复查要求里，措辞各不相同。现在规则只写在模板里，按「总结给谁看 → 由什么组成 → 各节 → 命题怎么写 → 画面和字幕 → 怎么做 → 格式」排列，后面是三份模板骨架。
- 模板里新增「自查」清单。网页 AI 的结尾提醒和复查轮直接引用它，不再另写一遍；Agent 和模型 API 路线也能看到这份清单。你自己的模板有「自查」一节时，用的就是你写的清单。
- 主线与单元：
  - 每个条目只在一处列出它的下级；主线里来自单元的条目只写编号，不再把单元里的整棵子树抄一遍。
  - 「讲者接上」引的是讲者把这一点连到主结论的那句话，不是讲者说出这一点本身的话；没有这样的话，或者主结论是总结者归纳的，就写「总结者归纳」。
  - 主结论讲者没有直接说、由总结者归纳的，也写进详细内容最后的「总结者归纳」一段，写出它的前提。
  - 只收和别的条目有关系的条目，没有关系的只留在详细内容里，不为了放进单元编出关系。
  - 单元标题不再写时间范围，单元不按时间段切。
- 对这些观众说要他们怎样的（「这门课不许手写代码」），是放进「需留意」的事项；泛泛地说事情应当怎样的，才是命题。
- 你改过的「标准」副本照旧保留，设置里会提示自带模板有更新；从没改过的副本自动换成新版。

**代码改动：**

- 命令行：`prompts/summary.md` 重写；`templates.checklist` 取出模板的「自查」清单；`packing.py` 的结尾提醒和复查要求改为引用它（`reminder`、`review_section`）。
- 文档：新增 `docs/summary-requirements.md`，逐条列出总结规则要做到的事，以及每条写在模板的哪里。
- 测试：「自查」只写一次、提醒和复查从模板里取。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.4.1.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.4.1/video_agent-1.4.1-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
