1.5.0 起，总结里的「主线与单元」改由程序照详细内容里写的关系排出，模型不再自己写这一节；还修掉了网页 AI 复查时会丢掉课件页的问题。

**改动：**

- 主线与单元由程序排：
  - 模型只在详细内容里写关系，写在命题行的标签后面：`← P1, P2`（支撑）、`反驳 P4`、`步骤 P39`（事件的一步）。主结论下面一行 `接上：`，列出它从各单元接过来的条目和每条的来源。
  - 保存时程序把有关系的条目连成一棵棵树，每棵是一个单元，以根的命题为题，放在根所在那一段的标题下；主线列出接到主结论的每一条。每个条目只展开一次，别处写「（在别处展开）」。模型自己写这一节时，常漏掉有关系的条目、把一个条目写进两个单元，或者和正文的关系对不上；现在这几种错不会再有。
  - 主线与单元里的编号都能点：在桌面程序里点了，会滚到详细内容里的那一条并短暂标出。
  - 总结者自己展开的「拓展」单元照旧由模型写在这一节里，程序保留。
  - 关系里用了不存在的编号、接到主结论的条目没写来源的，保存时报出来，Agent 和网页 AI 的复查轮会拿到这些问题。
  - 命题行只写命题本身，一句话；场景、数字、做法写在下面的子行。
- 「讲者接上」不再要求引讲者原话，改为写讲者说的时间，再转述讲者怎样把这一点连到主结论，不加引号。字幕是口语加语音识别，原样摘出来往往不成句。
- 只对带着新标记的模板这样排，自带的「标准」带着。你改过的「标准」副本照旧保留，设置里会提示自带模板有更新；没合并之前，你的副本仍按原来的写法由模型写主线与单元。

**修复：**

- 网页 AI 复查时，稿子链接的课件页（`slide-extraction/`、`slides/` 里的图）会被当成「发了但没用」，从画面集里去掉，下一轮就看不到了。现在三个文件夹的图都认，画面行的说明也不再只写 `frames/`。

**代码改动：**

- 命令行：新增 `forest.py`（从详细内容读出关系，排出主线与单元，报出排不出来的地方），导入和 `summarize` 保存前都运行它；`picture_review.FOLDERS` 统一认三个图片文件夹，`summary_review.py` 的链接检查用它；`prompts/summary.md` 按上面的写法修改。
- 桌面程序：总结页里指向 `#P<n>` 的链接滚到详细内容里那一条。
- 文档：重新整理成中文的需求、设计、参考、运行和约定几类，入口是 `docs/README.md`；旧的决策记录归档。新增写法检查 `scripts/lint_writing.py`。
- 测试：主线与单元的排法（单元、主线、只展开一次、拓展单元保留、Agent 导入）、课件页链接留在画面集里。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.5.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.5.0/video_agent-1.5.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
