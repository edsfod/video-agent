**新增：合集一键压缩。** 合集页「处理未处理的」旁边加了「压缩各集」，把各集都排进压缩；压缩过的、已经是 AV1 或 HEVC 的自动跳过。其中有不是本程序下载的视频时先问一次，选「取消」只压缩下载的那几集。

**修正：找不到装在别处的 DeepSeek Harness。** 它的安装程序没有把 `dsh` 加进 PATH。现在 PATH 里找不到时，到 DeepSeek Harness 的安装目录里找（目录从 Windows 的卸载记录里读，装在 D 盘等其他盘也能找到），设置 → 其他 Agent 里勾上就能用。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.9.1.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.9.1/video_agent-0.9.1-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
