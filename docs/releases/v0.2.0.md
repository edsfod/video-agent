**新增：检查更新。** 桌面程序启动时会在后台查一次有没有新版本（设置里可以关掉），有新版本时“设置”按钮旁出现红点；在设置里可以随时检查、下载、安装。不会自己下载，也不会自己安装。

- 下载完点“重启并安装”，程序会退出、静默安装新版本，再自动打开；设置和工作区都保留。装过 Agent 插件的，更新后会自动刷新成新版本。
- 只下载和当前版本不同的部分。拿 0.1.1 和这一版比，不同的部分约 19 MB，整个安装包约 160 MB。
- 依次尝试 github.com、GitHub API 和下载镜像；设置里也可以填自己的镜像。每次更新都带签名，镜像给出的文件对不上签名就不会安装。
- 都连不上时，会给出发布页链接，可以手动下载。

**安装时说明会改 PATH。** 安装向导里多了一页：把自带的命令行工具加进当前用户的 PATH（默认勾选，可以取消），卸载时移除。更新时沿用上次的选择。

**修正：** 卸载时会删掉 `%LOCALAPPDATA%\video-agent-gui-updater` 里的安装包副本。0.1.1 卸载后会把它留下（约 160 MB）。

从 0.1.1 升级要手动下载这一次，之后的版本就可以在程序里更新了。

- **桌面程序**：下载 `Video-Agent-Setup-0.2.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.2.0/video_agent-0.2.0-py3-none-any.whl
  ```

**第三方组件**：安装包里的 FFmpeg 7.1（gyan.dev essentials 构建，经 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 提供）以 GPLv3 发布，源码见 [ffmpeg-7.1.tar.xz](https://ffmpeg.org/releases/ffmpeg-7.1.tar.xz)，这个构建包含的第三方库及其说明见 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)。yt-dlp 以 Unlicense 发布，Python 以 PSF 许可证发布。
