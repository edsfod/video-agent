1.3.2 让网页 AI 看到视频的每一张画面：图太多放不进 50 个文件时，整幅画面也拼成总图发过去，不再抽掉一部分。

**修复：**

- 以前只有屏幕页会拼成总图，整幅画面一律单张放，放不下就均匀抽掉。拿一个 15 分钟的视频看：16 张屏幕页、99 张整幅画面，第 1 轮只发了 49 张，后面几轮只发补截的候选，有 66 张 DeepSeek 从头到尾没看到，也就一直留在那套画面里，没人判断有没有用。现在按「都单张 → 屏幕页单张、画面 2×2 → 都 2×2 → 屏幕页 2×2、画面 3×3 → 都 3×3」的顺序，用第一种放得下的，屏幕页总比画面拼得松，字更清楚。工作区里的视频都能一次发完：这个 15 分钟的视频 41 个文件，一个 90 分钟、87 张屏幕页和 166 张画面的课也是 41 个文件。只有连 3×3 都放不下才会少发，并在提示里写明少了几张。
- 总图只是发送时用的。总结里链接的、导入后保存的，仍然是每一张原图。提示里也写明了：总图里一格是一张图，以每格左下角的编号和时间为准，讲者和屏幕并排的分屏、画中画都算一张，不要拆成两张。

**改动：**

- 「总结」页选「DeepSeek 网页」后，按钮旁边可以设最多跑几轮，默认 6 轮，改过会记住。
- 「画面」页的下拉框里，每套画面后面写明是哪份总结用它写的。某一轮没有增减图片时会沿用上一套，比如第 5 轮的总结用的是第 3 轮那套，以前看起来像对不上。
- 版本树出现之前留下的「以前去掉的画面」不再自动转成一套。

**代码改动：**

- 命令行 `evidence.py` 的 `plan` 按上面的顺序给屏幕页和整幅画面挑拼法，「DeepSeek 网页」、「导出文件夹」和模型 API 都用它；`packing.py` 在提示里说明总图和分屏；`pictures.py` 去掉了把旧「不用」名单转成第一套的代码。
- 桌面程序：`chat-rounds.js` 按任务带的轮数上限停，设置里新增 `webRounds`；`video-view.js` 在画面集合的名字后面写上用它的总结。
- 测试：新增整幅画面拼成总图、所有画面都发出的测试，以及界面上设置轮数上限的测试。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.3.2.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.3.2/video_agent-1.3.2-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
