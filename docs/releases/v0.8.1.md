**新增：外观设置。** 「设置」里可以选「跟随系统」「浅色」或「深色」，选了马上就能看到效果，点「保存」才记住。

**改进：更新下载更快。** 更新要下载的几段数据现在同时下载，不再一段接一段地等。按 0.7.0 到 0.8.0 那次的数据实测，下载这一步从约 8 秒降到约 4 到 5 秒。下载更新的是正在运行的版本，所以这次升级到 0.8.1 还是原来的速度，再往后的更新才会变快。

**修正：**

- 总结里的代码块（比如网页 AI 画的示意图）不再每一行之间多出一个空行，整块显示。原因是导入时 Windows 的换行被多算了一次；已经受影响的总结，用这一版重新导入一次即可。
- 程序写出的总结、字幕等文件统一使用 `\n` 换行。
- README 最上面的截图左边是浅色、右边是深色，不管 GitHub 用哪种主题都能看到两种外观。

从 0.6.2 及以后的版本更新，只下载变化的部分；设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.8.1.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.8.1/video_agent-0.8.1-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
