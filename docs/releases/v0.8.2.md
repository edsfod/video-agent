**新增：其他 Agent。** 除了 Claude Code 和 Codex，也可以让 pi、Hermes Agent、DeepSeek Harness 在后台写总结，或者填你自己的命令行 Agent。在「设置」→「其他 Agent」里选一个，总结页和合集页就多一个对应的选项。它们读同一份 skill，写出的总结和其他方式一样另存为版本。注意：这些 Agent 以你的身份运行命令，不像 Codex 那样只能动工作区。

**新增：导出文件夹。** 「复制材料」多了「导出文件夹」，给不收 zip、一次能传的文件数有上限的网页 AI 用（比如 DeepSeek 网页版，最多 50 个文件）。文件夹里是提示词和按上限挑出的图片：屏幕页太多时拼成总图，剩下的名额给整幅画面。上限默认 50，可以改，会记住。以一节 100 分钟、109 页课件的课为例：28 张总图加 21 张画面，再加提示词，正好 50 个文件。把文件夹里的文件全部传给网页 AI，写好后照常「导入总结」，画面链接照样能点开。

**修正：**

- 合集里的视频导入总结、换版本或删除版本后，左边侧栏里这一集的状态会马上更新，不再停在「已处理」。

从 0.6.2 及以后的版本更新，只下载变化的部分；从 0.8.1 更新到这一版，是第一次同时下载这几段数据。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.8.2.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.8.2/video_agent-0.8.2-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
