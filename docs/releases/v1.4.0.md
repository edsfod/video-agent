1.4.0 重做了总结模板，新增删除视频和 Antigravity 总结路线，总结的每个版本会记下它是从头写的，还是在哪一版上改的。

**新功能：**

- 删除视频。视频列表标题旁点「选择」，可以多选后一起删；视频页也有「删除…」。删除时会删掉这个视频的处理文件夹（字幕、画面、所有总结版本），并把它从各个合集里移除。视频文件只在它是本程序下载的（在工作区的「下载」文件夹或跟随合集的下载文件夹里）时才删，旁边的字幕和信息文件一起删；从自己电脑里添加的视频文件不动。命令行是 `video-agent delete`。
- Antigravity 路线。总结页多了一条路线：在正在运行的 Antigravity 桌面版里新开一个对话，让它的 Agent 按 skill 写总结并保存，你可以在 Antigravity 的窗口里看它做到哪一步。默认模型 gemini-3.8-flash-high。Antigravity 要先打开并登录好。设置里的 Agent 预设也加了 Antigravity 命令行（agy）。
- 版本谱系。每个总结版本记下它是「从头写」还是「改自」某一版：导入时，新稿有五分之一以上的内容行和某个已有版本一字不差，就记为改自那一版（模板自带的行不算），并提示一句。版本下拉框里显示「从头写」或「改自 某月某日 时:分」。之前保存的版本两样都不显示，因为没有记录。

**改动：**

- 自带模板只剩「标准」，原来的「命题分析」并进了它。你改过的模板副本照旧保留；从没改过的副本，在自带模板更新后会自动删掉，以后跟着自带的走。
- 「标准」模板的规则按三条原则重写：
  - 一个正文、两种视图：详细内容是正文，每样东西只写一次、按顺序编号；要点是按时间看的视图（读者只读这一节也不能漏掉的东西，按视频先后排，不分类），主线与单元是按逻辑看的视图，两者都只用编号指向正文。所以先写详细内容，再写要点和主线。
  - 每句话按它做什么归类：可真可假的说法、数字、事件写成命题；要求或告知的（要做什么、禁止什么、怎么考核、截止时间）放进「需留意」，讲者为它讲了理由也一样，理由才写成命题。
  - 每个命题、每层关系都注明来源：讲者、讲者引用的人（「引用」），或总结者自己（「补全」「拓展：」「核对：」「总结者归纳」）。
  - 主线与单元：先找出讲者围绕一点展开、单看也能带走的单元（一个结论和它的论证，或一个演示、故事、案例和它说明了什么），每个单元自成一棵树，不连到别处。几个单元共同服务的结论是主线，各单元为它贡献的命题写在主线里，注明「讲者接上」（附时间和讲者原话）还是「总结者归纳」；每个命题在里面只占一处。
  - 「拓展：」补读者缺的：逐点想视频默认观众知道什么、点到为止没说透什么，读者要看懂或用上需要的就补上。「核对：」写出处对不对、支撑够不够。
  - 每一点写多少看它值多少，没有价值的时间段直接略过，不再要求每段时间都写到。
- 网页 AI 多轮复查：
  - 后一轮覆盖本轮自己的上一稿；那一稿被手改过，或者换了模板，就另存一个版本，不覆盖。
  - 因为网络或限流没跑完的稿子会保存下来，备注写「未收敛」，下次在新对话里接着复查；跑完的写「已收敛」。
  - 新增两项检查：详细内容里在要点中一条都没有的段落，以及时间点放错段落的命题。超过 2 分钟没覆盖的讲话只提一次。
- Agent 路线：导入时也跑检查（缺的节、超过 2 分钟没覆盖的讲话、要点覆盖、时间点错段、超出视频长度的时间点）。查出问题时 Agent 可以改一次再导入，覆盖它刚存的那一稿；改完还有的问题照实列出，稿子照存。发给 Agent 的任务要求从处理结果从头写，不读已有的总结，除非你的要求里提到了它们。

**修复：**

- Agent 开跑前备份当前总结时，会把当前总结的来源错标成这个 Agent，而文字其实没变，还多出一份一模一样的版本（10 月 28 日起就有）。现在备份不改标签，Agent 做完后，用不上的备份自动收掉；Agent 直接改写了总结的，才记到它名下。
- DeepSeek 网页：图片上传恰好在两次检查之间以 Server busy 结束时，发送按钮已经可以点，程序可能不点重试就把消息发出去。现在上传状态和发送按钮在同一时刻读取。这个问题是 GitHub 上的端到端测试时好时坏查出来的。

**代码改动：**

- 命令行：新增 `removal.py` 和 `delete` 命令；`pack --resume` 接着没收敛的那一轮；`versions --settle`；`versions.py` 给每个版本记 id 和 `based_on`，`closest` 按逐字相同的行找出它改自哪一版；`summary_review.py` 新增要点覆盖、命题错段的检查，以及一轮可以覆盖哪一稿（`own_draft`）、从哪里接着跑（`unfinished`）；`importer.py` 给 Agent 的草稿也跑检查；`templates.py` 只剩一个自带模板，并清理没改过的副本；`prompts/summary.md` 和 `packing.py` 按上面的结构重写。
- 桌面程序：`antigravity.js`（通过 Antigravity 本机服务开对话、跟进度、停止）；`jobs.js` 的 Antigravity 路线，以及 Agent 跑完后的 `versions --settle`；`programs.js` 加 agy 预设；`deepseek.js` 把上传状态和发送按钮放在一次读取里；页面加多选删除和版本谱系的显示。
- 测试：删除、版本谱系、备份与收掉备份、Agent 草稿检查、要点覆盖、未收敛续跑、Antigravity 步骤显示、agy 模型列表。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.4.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.4.0/video_agent-1.4.0-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
