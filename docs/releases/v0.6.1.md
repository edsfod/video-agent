**改进：**

- 合集里的视频不再挤在「视频」列表里：它们列在侧栏合集名下，点合集左边的 ▸ 展开，点某一集直接打开它的页面；打开着的合集和正在看的那一集会自动展开、高亮。视频移出合集后回到「视频」列表。
- 处理页的选项说清楚了：屏幕页每次处理都会截取，不需要另装软件。原来的「提取 PPT 幻灯片」改名为「另外用 AutoSlides Extractor 提取幻灯片（需自己安装）」，写明写总结用不到它；电脑上没有找到 AutoSlides Extractor 时这一项变灰并说明原因。
- 字幕卡片只写来源（比如「B 站 AI 字幕」「同名字幕文件」），不再把很长的字幕文件名整个列出来；完整文件名放在鼠标悬停提示里。
- 「设置 → 更新」里的更新说明不再出现横向滚动条，长命令会自动换行。

从 0.6.0 更新到这一版，只下载和 0.6.0 不同的部分；从更早的版本更新仍是整包下载。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.6.1.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.6.1/video_agent-0.6.1-py3-none-any.whl
  ```

  新命令 `video-agent tools` 列出会用到的外部程序（FFmpeg、ffprobe、yt-dlp、AutoSlides Extractor）各在哪里，没找到的写明。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
