1.2.1 修复「DeepSeek 网页」写总结时的两个问题。

**修复：**

- DeepSeek 窗口被别的窗口挡住、最小化时，回答有时读不全，导入报「总结为空或太短」。原因是 Windows 会把被完全挡住的窗口当成看不见，页面停止绘制，DeepSeek 写出的内容没有进到页面里（页面上的复制按钮不受影响，所以复制出来是完整的）。现在 DeepSeek 窗口在后面、最小化时也照常绘制，程序能读到完整的回答。
- 附几十张图时，只要有一张上传失败，以前会把所有图片重新上传一遍，连续几次都有一张失败就整个任务出错。现在只把失败的那几张删掉重传，每张最多 3 次；还不行就这次不发那几张，任务输出里会写是哪几张。上传一直传不完、回答只是「服务器繁忙」时，仍然整条重发。
- 导入失败时，DeepSeek 的回答会记进这个任务的日志，可以看原因或手动导入。

**代码改动：**

- `main.js` 启动时关掉 Chromium 的窗口遮挡检测（`CalculateNativeWinOcclusion`），`deepseek.js` 的窗口关掉后台节流；两样都要，只关后台节流时页面仍然不绘制。
- `deepseek.js` 按附件的文件名找出上传失败的附件，删掉后单独重新附上；`chat-rounds.js` 导入失败时把回答写进任务日志。
- 测试：模拟 DeepSeek 页面加上与真实页面同样结构的附件和一次上传失败，检查只有失败的那张重传了。

从 0.6.2 及以后的版本更新，只下载变化的部分。设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-1.2.1.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v1.2.1/video_agent-1.2.1-py3-none-any.whl
  ```

  用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。`compress` 需要带 SVT-AV1 的 FFmpeg。命令行没有改动。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`、`SVT-AV1-v4.2.0.tar.gz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.9.0 相同。
