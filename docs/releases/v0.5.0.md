**新增：一键下载合集和播放列表。** 在左上角粘贴 B 站合集、播放列表这类链接点「下载」，会先告诉你这个列表叫什么、有几个视频，问你要不要全部下载；默认放进一个以列表命名的合集（名字可以改），下载完按顺序排好，直接在合集页里处理和总结。以前这类链接在窗口里下载会直接失败。

**改进：**

- 设置窗口右上角有了关闭按钮，按 Esc 或点窗口外面也能关。没改东西就直接关；改了东西会在底部提示「有改动还没保存」，可以选不保存或保存。保存按钮一直在窗口底部，不用滚到最下面找。查看 skill 和日志的窗口点外面也能关。
- 合集页「加入」那一行：下拉框加宽，先提示「从视频列表选一个…」，选好才能点「加入」；视频列表里没有可加的视频时会直接写明。新增「从文件添加…」，可以直接选本地视频加进合集。

已装 0.2.0 到 0.4.0 的，在「设置 → 更新」里就能更新；设置和工作区都保留。

- **桌面程序**：下载 `Video-Agent-Setup-0.5.0.exe`，直接运行即可覆盖旧版本。安装包没有代码签名，Windows SmartScreen 可能提示“未知发布者”，选“仍要运行”即可。
- **命令行工具**（需要 uv，不需要 git）：

  ```powershell
  uv tool install --force https://github.com/edsfod/video-agent/releases/download/v0.5.0/video_agent-0.5.0-py3-none-any.whl
  ```

  `download --json` 遇到代表列表的链接、又没加 `--playlist` 时，会多输出一行 `{"playlist": {...}}`，写明列表的标题和视频数。用 uv 安装时，FFmpeg 由 [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg) 从 PyPI 提供；电脑上已有的 ffmpeg 会优先使用。

本页附有安装包里 LGPL FFmpeg 的完整源码（`ffmpeg-9.0.2.tar.xz`、`dav1d-1.5.4.tar.xz`）和编译说明（`FFmpeg-BUILD.txt`），与 0.3.0 相同。
