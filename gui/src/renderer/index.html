总结任何视频

从左边选一个合集或视频。

添加本地视频，或粘贴链接下载，也可以把视频文件拖进窗口。

处理时先找视频自带的字幕；没有字幕时，可以选择用必剪转录（会上传音频）。

准备材料

提取字幕、抽取代表画面，自动找出屏幕区域（摄像头和屏幕拼在一起时只看屏幕那块）并截下每一页（屏幕页，每次都做，不需要另装软件），写出供总结用的材料。画面上限留空即不限，视频有多少就留多少。原视频不会被修改或移动。

画面布局

改正错字

把识别错的名字、术语改过来：原始字幕保留不动，另存一份整理版，之后的总结都用整理版。只填每次出现都错的写法；中文按原样匹配，如果错的写法同时也是正常的词（比如「写作」），别加在这里。

处理和压缩都很吃 CPU：一个压缩已经用上所有核心，同时压几个总共只快一点，各自都变慢，所以默认一次一个，其余的排队。同一个视频的处理、压缩和总结不会同时进行。

        
        
        
        

        
压缩视频

        
用 AV1 重新编码，分辨率不变，看不出画质差别：屏幕录像（画面基本不动）降到每秒 10 帧，大约剩原来的五分之一；摄像头画面大约剩一半多。已经是 AV1、HEVC 的视频（比如 B 站的）不再压缩。压好的文件先和原文件核对时长，再替换原文件，路径不变，处理结果和总结照常可用。压一节一个半小时的课要几分钟。

        
        
        
账号

        
有的网站要先在这里登录或打开一次，yt-dlp 才拿得到字幕或视频。登录状态只存在本机，只在下载那个网站的视频时交给 yt-dlp。用箭头调整顺序，不用的可以隐藏。

        

        

        
Agent 插件

        
把总结用的 skill 装进 Agent，之后在它们里面直接说“总结这个视频”即可。从本机安装，不需要 git，也不用联网；重复点击会刷新已装的版本，程序更新后也会自动刷新。pi、Hermes Agent、DeepSeek Harness 没有插件，是把 skill 文件夹复制到它们读 skill 的地方；别的 Agent 选它读 skill 的文件夹。在本程序里用它们写总结不需要先装。

        
          
          
        
        
          
          
          
          
        
        

        
其他 Agent

        
除了 Claude Code 和 Codex，也可以让别的命令行 Agent 在后台写总结：勾上的每一个都会出现在总结的方式里，命令可以改，也可以填你自己的。它们读同一份 skill 照着做。注意：这些 Agent 不像 Codex 那样只能动工作区，它们以你的身份运行命令。命令里写 {prompt} 的，任务放在这个位置；不写的，任务从标准输入传进去。

        

        
总结模板

        
模板是总结的规则和格式。几种总结方式和「复制材料」都按总结页上选的模板写。自带「标准」和「命题分析」两份：可以直接改，更新程序不会覆盖你改过的；也可以照着一份新建，起个名字，改成你自己的写法。

从浏览器导入

        
把你在浏览器里的登录状态拿过来：只留的 Cookie，存在本机，只在下载这个网站的视频时交给 yt-dlp。

        
直接读取浏览器

        
        
Firefox 可以直接读。Edge 开着时读不了，要先完全关掉（包括托盘里的）；新版 Chrome 把 Cookie 加密成只有它自己能读，读不出来，用下面的办法。

        

        
用扩展导出 cookies.txt

        
    
          
  1. 在 Chrome 或 Edge 里安装扩展 Get cookies.txt LOCALLY（开源，说明里写明不把数据发出去；Firefox 版在这里）。
    2. 
          
  2. 在浏览器里打开（）并登录。
    3. 
          
  3. 点浏览器右上角的扩展图标，选 Get cookies.txt LOCALLY，格式选 Netscape，点 Export，存成一个 .txt 文件。
    4. 
          
  4. 点下面的「选择 cookies.txt…」选这个文件。导入后可以删掉它：里面有你的登录状态。
