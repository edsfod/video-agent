总结任何视频

添加本地视频，或粘贴链接下载，也可以把视频文件拖进窗口。

处理时先找视频自带的字幕；没有字幕时，可以选择用必剪转录（会上传音频）。

准备材料

提取字幕、抽取代表画面，自动找出屏幕区域（摄像头和屏幕拼在一起时只看屏幕那块）并截下每一页（屏幕页，每次都做，不需要另装软件），写出供总结用的材料。画面上限留空即不限，视频有多少就留多少。原视频不会被修改或移动。

画面布局

改正错字

把识别错的名字、术语改过来：原始字幕保留不动，另存一份整理版，之后的总结都用整理版。只填每次出现都错的写法；中文按原样匹配，如果错的写法同时也是正常的词（比如「写作」），别加在这里。

哔哩哔哩账号

        
B 站只给登录的账号看字幕（包括 AI 字幕）。在这里登录一次，之后下载 B 站视频会把字幕一起存下来，处理时直接用，不用转录。登录状态只存在本机，只在下载 B 站视频时交给 yt-dlp。

        
          
          
          
        
        
Agent 插件

        
把总结用的 skill 装进 Claude Code 或 Codex，之后在它们里面直接说“总结这个视频”即可。从本机安装，不需要 git，也不用联网；重复点击会刷新已装的版本。

        
          
          
        
        

        
其他 Agent

        
除了 Claude Code 和 Codex，也可以让别的命令行 Agent 在后台写总结：选一个，或填你自己的命令。它会读同一份 skill 照着做。注意：这些 Agent 不像 Codex 那样只能动工作区，它们以你的身份运行命令。命令里写 {prompt} 的，任务放在这个位置；不写的，任务从标准输入传进去。

        
        
        
总结规则和模板

        
几种总结方式和「复制材料」都按这份规则写。可以改成你自己的写法，比如更长、更短、固定要哪几节；更新程序不会覆盖你的版本。
